# UDP Voting System

## Description
A real-time voting system using UDP sockets with application-layer encryption.

## Features
- Multi-client support
- Encrypted communication (Fernet)
- Duplicate vote detection
- Live vote counting

## How to Run

### Server
cd server
python server_main.py

### Client
cd client
python client_main.py
